# Web Calculators & Converters

A lightweight collection of interactive web tools built using pure **HTML** and **Vanilla JavaScript**.

Originally created as a practice project during *Datenverarbeitung* (Data Processing) classes in school to work with mathematical logic, DOM manipulation, and user input handling in the browser.

**Included Tools**
* Calorie Calculator (kalorien.html): Calculates kilocalories based on the drink volume (e.g. Coca-Cola).
* Geometry Calculator (berechnungen.html): Calculates diameter, circumference, and area of a circle based on the input radius.

**Tech Stack**
* HTML5
* JavaScript
